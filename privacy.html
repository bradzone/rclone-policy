Privacy Policy

Last updated: October 2026

This application is exclusively for private, personal use by its creator. It interacts directly between the user's local system and their personal Google Drive storage.

Data Collection and Usage

This utility does not collect, track, store, or transmit any personal data, identifiers, or credentials to any third-party servers. All interactions occur solely between the local device and Google's official API endpoints.

Third-Party Services

Data access complies with the Google API Services User Data Policy, using restricted scopes limited to the files created by the application itself.
